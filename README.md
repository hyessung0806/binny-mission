# 비니의 미션달력 🗓️⭐

매일 미션을 완수하면 부모가 도장을 찍어주고, 정해진 개수를 모으면 선물을 받는
**아이용 도장 미션 달력 PWA**입니다. 갤럭시탭·안드로이드·아이폰에서 **가족 코드**로 실시간 연동됩니다.

- 단일 파일(`index.html`) PWA — 빌드 없음
- 백엔드: Supabase (가족 코드 기반, 로그인 없음 / 도장 1개 = 1행)
- 도장은 **부모만**(부모 모드 비밀번호, 모든 기기 공유). 목표 달성 시 축하 🎉

## 사용법
배포 주소를 폰·태블릿에서 열고 **홈 화면에 추가**하세요.
처음엔 **"새로 시작"**으로 가족 코드를 만들고, 다른 기기에선 그 **코드를 입력**하면 같은 도장판을 공유합니다.
미션·목표·선물·부모 비밀번호는 제목을 길게 눌러 들어가는 **부모 모드 설정**에서 바꿉니다.

## 개발자 설정
`index.html` 상단의 `SUPABASE_URL` / `SUPABASE_ANON_KEY`에 본인 Supabase 프로젝트 값을 넣으면 연동됩니다.
백엔드 스키마는 `supabase/schema.sql`(별도)을 SQL Editor에 1회 실행하면 만들어집니다.

> anon 키는 공개돼도 안전합니다. **`service_role` 키는 절대 프론트엔드/깃에 넣지 마세요.**
> 두 값을 비우면 "이 기기 단독 모드"(로컬 저장)로 동작합니다.

별 시리즈(`byeol-sudoku` · `byeol-sugarugi`)의 연동형 자매 앱입니다.
